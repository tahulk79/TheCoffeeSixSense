## Supplied references actually reviewed

- `C6S_Codex_Handoff_v0.3.zip`: read the handoff and full master GDD; extracted
  and reviewed the nested prototype `app.js`, HTML, CSS and README.
- The handoff/GDD call for Ethiopia **Washed** and Colombia **Honey**. The
  prototype code instead calls them Ethiopia Natural and Colombia Washed.
  Integration follows the handoff/GDD and existing starter archetypes.
- The prototype adds each stage's full water instantly on one tap, has English
  guided-stage strings even in Vietnamese mode, and does not link pour timing
  to its score. It only displays four simulated attributes, despite the GDD's
  six subjective descriptors. Its unversioned storage silently discards invalid
  data and repeated save clicks append duplicates.
- The prototype's synthetic extraction/acidity formula is **not imported**. It
  would undo the existing scientific caveats and imply unjustified flavor
  relationships. No empirical data or trained model is added.

Original reference documents are retained in `docs/design/v0.3/`. They contain
historical proposals; the narrower handoff and current Pages architecture take
precedence. The prototype is a reference, not a replacement application.

## Integrated behavior

A visible counter navigation button opens the guided **The First Pour** lab.
The current real-time counter remains available, with its music, water/timers,
progression, bean library, legacy journal and actual-brew collector preserved.

- Three representative fictional lots with game presets; editable dose, ratio,
  grind, temperature and planned recipe time, validated with native form bounds.
- Three explicit stages: bloom (20%), main pour (50%), final pour (30%).
  Continuous hold or one-tap toggle, keyboard Space/Enter, visible ml and water
  progress, stage gates and restart. Exact total water is bounded even for
  fractional dose/ratio; the last stage absorbs rounding.
- Active pouring time is shown separately from recipe time. Play is shortened
  to approximately 12 active seconds for all water, with deliberate pauses
  between stages. This is neither an extraction simulation nor real bloom timing.
- Recipe score `first-pour-0.3.1` is deterministic, weighted distance from a
  fictional preset, capped 0–100. Grind/temp/ratio/recipe-time affect it; dose
  scales water at a fixed ratio; touch timing does not change the score. No
  TDS, extraction yield, or flavor intensities are inferred.
- Six optional **user-entered** sensory intensities, separate optional enjoyment,
  context (game reflection / self-reported separate real tasting), notes and
  next change. No average of sensory axes is treated as enjoyment. “Sixth Taste”
  is explicitly metaphorical, distinct from the six descriptors.
- Coffee Memory: save/update without duplicate IDs, reload, view, A/B compare,
  changed-field explanation, JSON export and individually confirmed deletion.
  When multiple recipe variables change, comparison warns against attributing
  the difference to one variable. It never claims causal proof.
- Independent versioned key `c6s.first-pour.v03`. Existing stores are not migrated,
  overwritten or mixed into scientific exports. Clear local-only/data-loss text,
  corrupt-data recovery download, quota-failure draft export and save retry.
- Lightweight original CSS brewing station, warm colors and bloom/water movement;
  reduced-motion support. No 3D engine, copied art, backend, accounts or tracking.

## Release and limits

This change is submitted as a feature PR. The supplied handoff requires owner
approval before merge/publish. **No deployment of v0.3 is performed by this PR.**
The URL above is the verified current production site, not a preview of v0.3.
No branch-specific Pages preview is configured. Review locally with
`npm ci && npm run dev`, or serve the generated `docs/` directory over HTTP.

Safari/iPad M5 hardware, subjective playtesting, perceived music quality, and
retention remain unverified. P0 uses accessible comparison tables and intensity
inputs; a radar chart and all longer-term GDD systems remain backlog. This
release is an educational illustrative game, not a calibrated brewing tutor.
